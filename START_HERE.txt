                        📞 SUPPORT & TROUBLESHOOTING
█████████████████████████████████████████████████████████████████████████████████

Problem: setup.bat doesn't work
Solution: 
  • Make sure Python 3.8+ is installed
  • Check Windows PATH includes Python
  • Run from Command Prompt (not PowerShell)

Problem: Telegram messages not arriving
Solution:
  • Check bot token in .env file
  • Check bot is admin in Telegram group
  • Check chat ID is correct
  • Review Vercel logs

Problem: Git won't push
Solution:
  • Add GitHub remote: git remote add origin URL
  • Check you have push permissions
  • Verify internet connection

Problem: Vercel deployment fails
Solution:
  • Check requirements.txt is complete
  • Verify Python 3.8+ support
  • Review Vercel build logs
  • Ensure env vars are set
