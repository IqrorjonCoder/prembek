🚀 3-STEP DEPLOYMENT:
======================

STEP 1: Test Locally
─────────────────────
Windows:
  setup.bat

Mac/Linux:
  bash setup.sh

Then: http://localhost:5000


STEP 2: Push to GitHub
───────────────────────
git init
git add .
git commit -m "Initial commit"
git push origin main

(Make sure .env is NOT in git status!)


STEP 3: Deploy to Vercel
─────────────────────────
1. vercel.com → Import GitHub repo
2. Add environment variables:
   - TELEGRAM_BOT_TOKEN
   - TELEGRAM_CHAT_ID
3. Click Deploy
4. Get your live URL!
