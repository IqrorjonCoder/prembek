🚀 QUICK START - GIT VA VERCEL DEPLOY

=== STEP 1: LOCAL TEST ===

Windows:
  setup.bat

Mac/Linux:
  bash setup.sh

Then open: http://localhost:5000


=== STEP 2: INITIALIZE GIT ===

```bash
cd x:\projects\prembek\test_all_prem

# Initialize git
git init
git config user.name "Your Name"
git config user.email "your@email.com"

# Add all files (except .env - auto ignored)
git add .
git status  # Check that .env is NOT listed

# Commit
git commit -m "Initial commit - Prem_Bek secure application"

# Set main branch
git branch -M main

# Add remote (replace YOUR_USERNAME and REPO)
git remote add origin https://github.com/YOUR_USERNAME/prembek-test.git

# Push
git push -u origin main
```


=== STEP 3: VERCEL DEPLOY ===

Option A: Web Interface
1. Go to https://vercel.com
2. Sign in with GitHub
3. Click "Add New Project"
4. Select your GitHub repository
5. Click "Import"
6. Add Environment Variables:
   TELEGRAM_BOT_TOKEN = 7548520724:AAGSRnqwBeb35JM-6609-4WhLphX9dIBTA4
   TELEGRAM_CHAT_ID = -1003990120376
7. Click "Deploy"

Option B: Vercel CLI
```bash
npm i -g vercel
vercel login
vercel
# Follow prompts, add environment variables when asked
```


=== STEP 4: TEST ON VERCEL ===

1. Vercel will give you a URL (like https://prembek.vercel.app)
2. Open that URL
3. Test all pages:

5. Share URL with users!


=== SECURITY CHECKLIST ===

Before pushing to Git:
✓ .env file exists locally
✓ .env NOT listed in "git status"
✓ .gitignore has ".env" on line 2
✓ app.py uses environment variables
✓ No hardcoded API keys in code

Before deploying to Vercel:
✓ Repository is public on GitHub
✓ Environment variables added to Vercel dashboard
✓ debug=False in app.py
✓ vercel.json is configured
✓ requirements.txt has all dependencies


=== IMPORTANT ===

⚠️ NEVER commit .env to Git!
   (.gitignore prevents this, but don't force add it)

⚠️ ALWAYS set environment variables in Vercel dashboard!
   (Not in code, not in .env file that's committed)

⚠️ KEEP BOT TOKEN SECRET!
   Don't share with anyone


=== WHAT'S PROTECTED ===

✓ Telegram bot token - in environment variables
✓ Chat ID - in environment variables  
✓ Secrets - never in code
✓ API calls - through secure backend
✓ HTTPS - automatic with Vercel
